# 奶茶销售平台 - 产品需求文档 (PRD)

## 1. 产品概述

这是一个高端奶茶销售电商平台，采用极简主义美学设计，灵感来源于喜茶(heytea.com)的品牌风格。平台通过整洁的布局和冷静的色调来突显高质量的产品摄影，为用户提供优雅、流畅的购物体验。

- **核心目标**：打造一个视觉精美、功能完善的奶茶在线销售平台
- **目标用户**：追求品质生活的年轻消费者、奶茶爱好者

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 邮箱注册/登录 | 浏览产品、购物车、下单支付、查看订单 |
| 管理员 | 后台分配 | 产品管理、订单管理、用户管理 |

### 2.2 功能模块

1. **首页**：品牌Hero区、精选产品展示、品牌故事
2. **产品目录页**：产品分类筛选、产品网格展示、搜索功能
3. **产品详情页**：产品大图、规格选择、加入购物车
4. **购物车页**：商品列表、数量调整、价格计算、结算入口
5. **用户认证**：登录/注册表单、用户状态管理
6. **结账页**：配送信息、支付方式(Stripe集成)、订单确认
7. **订单页**：订单历史、订单详情查看
8. **管理后台**：产品管理(CRUD)、订单管理、数据统计

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：米白色(#F8F6F3)作为背景，深灰(#2D2D2D)作为主文字，品牌绿(#4A7C59)作为强调色
- **辅助色**：浅灰(#E8E6E3)、奶茶色(#D4A574)、淡绿(#E8F0E8)
- **按钮风格**：圆角矩形(8px)，极简扁平设计，悬停时轻微上浮阴影
- **字体**：
  - 标题：Playfair Display (衬线字体，优雅高端)
  - 正文：Noto Sans SC (中文无衬线，清晰易读)
  - 字号：标题32-48px，正文14-16px，小字12px
- **布局风格**：大量留白，居中对齐，卡片式产品展示，顶部固定导航
- **图标风格**：线性图标，1.5px描边，简洁现代

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | Hero区 | 全屏高度，渐变背景(#F8F6F3到#E8F0E8)，居中大标题，淡入动画 |
| 首页 | 精选产品 | 4列网格，卡片白色背景，悬停时图片放大1.05倍+阴影 |
| 产品目录 | 产品网格 | 3-4列响应式网格，产品图片占卡片70%，下方名称和价格 |
| 产品详情 | 产品展示 | 左侧大图(60%)，右侧信息区(40%)，规格选择器为圆角按钮组 |
| 购物车 | 商品列表 | 左侧商品信息，右侧数量和价格，底部固定结算栏 |
| 结账页 | 表单区 | 极简表单，输入框无边框仅底部线，聚焦时显示品牌绿 |
| 管理后台 | 列表区 | 表格布局，操作按钮为文字链接，侧边导航 |

### 4.3 响应式设计

- **桌面优先**：主要针对桌面端设计，保证大屏幕最佳体验
- **平板适配**：产品网格调整为2-3列，导航保持不变
- **移动端适配**：单列布局，底部固定导航栏，触摸优化

### 4.4 动效设计

- **页面过渡**：淡入淡出，300ms缓动
- **产品卡片**：悬停时图片scale(1.05)，阴影加深，过渡400ms
- **按钮交互**：点击时scale(0.98)，100ms快速响应
- **导航滚动**：滚动时导航栏背景由透明变为白色，添加阴影

## 6. 技术要求

### 6.1 支付集成

- **Stripe集成**：使用Stripe Checkout或Stripe Elements
- 支持信用卡支付
- 支付成功后跳转订单确认页

### 6.2 用户认证

- 邮箱+密码注册登录
- JWT Token认证
- 登录状态持久化

### 6.3 数据存储

- 产品数据：本地JSON文件或数据库
- 用户数据：数据库存储
- 订单数据：数据库存储
- 购物车：本地存储 + 数据库同步
